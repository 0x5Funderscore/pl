# `pl`

Command-line music player for PowerShell

Requires PowerShell Core version 7 or later (not Windows PowerShell)

[Install PowerShell on Windows, Linux, and macOS (Microsoft Learn)](https://learn.microsoft.com/en-us/powershell/scripting/install/install-powershell?view=powershell-7.6)

Also requires FFmpeg to be installed and on PATH

For information, run `Get-Help` on this script file in PowerShell
